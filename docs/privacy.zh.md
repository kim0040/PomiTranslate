# 数据、隐私与 API 密钥

[English](privacy.en.md) · [한국어](privacy.md) · [日本語](privacy.ja.md) · [简体中文](privacy.zh.md)

> 本页是简体中文文档；应用界面目前仅支持韩语、英语和日语。

## 本地处理与对外发送的数据

世界选择、扫描和检查都在本地进行。运行 AI 翻译时，所选源文本、目标语言、翻译指令等请求内容会发送给**你选择的 API 提供商或自定义 endpoint**。请检查服务器名称、书籍、告示牌等文本中是否包含个人信息，并避免将其选作翻译内容。接收数据的提供商会按照其数据保留、训练和删除政策处理这些数据。

**检查更新**只会从 GitHub（`github.com/kim0040/PomiTranslate`）获取最新版本信息（`latest.json`）。不会发送世界文件、密钥、使用记录或安装标识符。你可以在 Settings → Updates 中关闭每日自动检查。帮助和关于页面的网页链接只会在默认浏览器中打开预设地址（GitHub、minecraft.net、提供商的 API 密钥申请页面和联系邮箱）。

查询模型支持信息和用量也会向所选提供商发送网络请求。查询 OpenRouter 公开模型目录时不会发送密钥或世界文本。用量查询和其他提供商的认证请求会使用已保存的密钥。润色翻译指令会单独发送一次 AI 请求。

桌面应用使用 JSONL sidecar，不会为界面打开 localhost 服务器。开发用 Vite 服务器和 legacy Web UI 是独立部分，运行方式不同。

## 应用保存的数据

设置、最近使用的世界路径、模型缓存、扫描计划与检查点、翻译报告和备份可能保存在应用数据中。这些内容可能包含路径、源文本或译文，因此不要将其原样上传为诊断材料或放入公开仓库。你可以通过 Settings → **Reset** 删除设置、最近使用的世界、可恢复的任务和模型列表；也可以选择同时删除已保存的 API 密钥。重置不会删除世界备份；若要删除备份，请自行删除数据文件夹。帮助中的 **Copy diagnostics** 与诊断导出仅包含应用版本、构建、操作系统、错误代码、请求类型、耗时、结果代码，以及核心诊断行的已知形态。自由文本（错误消息、路径、世界名称或文本、密钥）从生成时起就不会放入，也不会写入本地日志文件。目前不提供加密的便携式导出。更新和清理工具与数据的关系见[更新与数据保留（韩语）](updates-and-data.md)。

公开 Python 设置路径为：macOS `~/Library/Application Support/PomiTranslate`、Windows `%APPDATA%/PomiTranslate`、Linux `$XDG_DATA_HOME/PomiTranslate` 或 `~/.local/share/PomiTranslate`。原生 vault 使用 Tauri app-data 路径下的 `credentials/credentials.sqlite` 和 `credential-key/master.key`。隔离的 Eval identifier 使用独立根目录，不与普通应用共用数据。

## API 密钥

- 默认：**本地加密存储** — 使用 Rust SQLite、AES-256-GCM，以及每次安装单独生成的密钥文件。
- 可选：**仅限本次会话** — 重启应用后需要重新输入密钥。
- 可选：**操作系统钥匙串** — 仅在你选择该方式或执行导入现有密钥时访问。应用启动时不会自动读取并导入已有钥匙串密钥。

界面只显示密钥是否已保存及其保存方式，不会返回已保存的密钥文本。API 请求需要密钥时，Rust 会通过 stdin 将密钥传给 sidecar。公开设置 JSON 和世界备份中都不包含密钥。

在相同用户权限下，同时能读取数据库和加密密钥文件的进程可以解密密钥。我们不会将此设计描述为可防御恶意程序、账户被盗、内存或 swap 泄漏。不要自动同步这些文件，也不要将它们放入公开备份。请另外保护操作系统账户和磁盘。应用会检查数据文件夹和 vault 文件夹不是链接、属于当前用户且其他用户无法写入，但以相同用户身份运行的其他进程不在此项检查的保护范围内。

CLI 和 legacy UI 使用现有的操作系统 keyring／环境变量兼容方式，不会自动与桌面 vault 共享密钥。`.env.example` 是不含秘密的格式示例；不建议将真实密钥以明文保存在 `.env` 文件中。

请在 Settings 中更改或删除密钥。从 Local 切换到 Session／Keychain 时，应用会删除本地保留的密文，但不会自动删除导入来源中的现有操作系统钥匙串项目。如果密钥文件丢失或密文损坏，可能需要重新输入密钥。应用在操作系统钥匙串中的项目，仅限服务名为 `PomiTranslate`、账户名为提供商名称（例如 `openai`）的项目；只有 PomiTranslate 会写入这一命名空间。应用不会枚举钥匙串，也不会触碰其他任何项目。只有在你明确操作时才会删除这些项目：删除某个提供商的密钥、将该提供商从 Keychain 切换到其他存储方式，或在选择“删除密钥”的前提下重置应用（涵盖所有提供商）。已经不存在的项目视为已删除。如果操作系统拒绝删除，应用会提示无法删除该项目（`KEYCHAIN_UNCONFIRMED`），再次操作会再次请求删除。

## 费用与联系

应用本身无需购买或订阅。API 请求、推理、重试和润色翻译指令产生的费用由提供商的条款决定。用量查询的前后差可能包含其他任务或统计延迟，因此可能与本次任务的费用不完全相同。

请勿在公开 Issue 中附上 API 密钥、私人世界文件或完整日志。如需报告安全问题，请先将不含秘密信息的说明发送至 [mini0227kim@gmail.com](mailto:mini0227kim@gmail.com)。另请阅读[免责声明与权利说明](disclaimer.zh.md)。

设置和操作方法见[用户指南](user-guide.zh.md)；已验证的格式和平台范围见[支持矩阵（英文）（韩语）](support-matrix.md)。
