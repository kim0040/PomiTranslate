# PomiTranslate

**World Translator for Minecraft** — 翻译 Minecraft Java Edition 世界文本的桌面应用

<img src="../assets/brand/social/og_default_zh_v1.png" alt="PomiTranslate 简体中文介绍图" width="900" />

[English](../README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh.md)

应用界面支持**韩语、英语、日语和简体中文**。**翻译目标语言**是独立设置，可以输入你自己的语言名称。

当冒险地图中的告示牌、书籍和物品说明让你读不懂时，PomiTranslate 可以把这些文本转换成你熟悉的语言。先扫描世界，查看将要翻译的内容，再检查候选文本；你可以自己填写译文，也可以把剩余内容交给所选的 AI 提供商。任何文件写入前都会先创建并验证备份。

PomiTranslate 可以做什么：

- **安全扫描** — 不修改世界文件，也不调用 API，先查看将要翻译的内容。
- **检查与编辑** — 搜索、筛选和排除字符串，或直接填写自己的译文，并用术语表统一译名。
- **AI 翻译** — 支持 OpenAI、Gemini、Anthropic、OpenRouter、Comet 和自定义 endpoint。首次运行有设置助手引导，开始前显示预计请求数和费用范围，还可以设置费用上限。
- **应用前检查** — 先检查并修改译文，只重新翻译失败的句子；应用之后也可以在不发送 AI 请求的情况下修改译文。
- **安全应用** — 只有在备份验证通过后才写入变更，也可以恢复到之前的备份点。

> **开发中：** 主要流程已在 macOS Apple Silicon 的隔离开发应用中演练。签名安装包、Windows/Linux clean-machine 验证和最终的付费翻译流程仍未完成。[当前状态（韩语）](current-state.md) · [后续工作（韩语）](follow-up-work.md)

## 工作方式

PomiTranslate 会直接读取你选择的文件夹，不会把世界复制到应用内部。整个流程分为六步；扫描、检查和译文检查阶段都不会修改世界文件。

1. **选择世界** — 打开带有 `level.dat` 的 Java Edition 世界文件夹，或选择服务器根目录。应用会显示检测到的维度、世界数据格式（DataVersion）、世界内置资源包和已保存备份的数量。Bedrock 世界、旧版 `.mcr`、`.linear`，以及正在被游戏或服务器使用的世界，会在流程开始前被拦截。
2. **扫描** — 找出值得翻译的文本。扫描不会调用翻译 API，也不会写入文件；它会汇总唯一字符串数、出现位置总数、预计 API 请求数和文本类型。无法读取的区块或不支持的格式会作为警告报告，原文保持不变。
3. **检查** — 按类型或状态搜索、排序和筛选候选文本。可以排除不想翻译的字符串，或为某个字符串填写自己的译文。同一句原文出现在多个位置时只翻译一次，再应用到所有位置。
4. **执行** — 确认目标世界、翻译语言、提供商和模型、要发送的字符串数、预计请求数和费用范围、可选的费用上限以及安全备份，然后开始执行。进度页面会显示剩余时间和最近翻译，设置了上限时会在达到上限时停止。翻译期间不会写入世界文件。
5. **检查并应用** — 默认情况下，写入之前会先打开译文检查页面。你可以修改译文（会验证格式代码），只重新翻译失败的句子，然后在备份验证通过后应用到世界。应用之后，还可以通过“编辑译文”恢复该任务的备份，并在不发送任何 AI 请求的情况下重新应用已保存的译文和你的修改。
6. **结果与恢复** — 查看已修改文件、已翻译/失败/保留原文的字符串、使用的 token 和报告的费用。需要撤销时，可以在备份管理中恢复到任意备份点；恢复前的状态会保留为 recovery snapshot。

## 功能

### 扫描与检查

- 在翻译或写入之前查看候选文本和覆盖范围。
- 按世界顺序、原文、出现频率或类型排序，按类型或状态筛选，并批量包含或排除。
- 查看某个字符串的所有出现位置并填写手动译文。只应用手动译文时，不需要翻译 API 请求。
- 跳过已经使用目标语言书写的文本，减少重复翻译费用。
- 易读的位置显示（维度和坐标）、复制传送命令、右键或键盘菜单，以及批量包含/排除的撤销。
- 扫描页面显示最近扫描、最近翻译的概要，以及继续未完成任务的卡片。

### 术语表

- 提供适用于所有世界的术语表和按世界划分的术语表，可指定始终按固定译法翻译或保留不翻译的术语。支持 JSON/CSV 导入导出，也可以直接从候选文本添加。
- 翻译请求只包含该批文本中出现的术语。如果回答违反规则，应用会带着提醒再请求一次，仍不符时标记为待检查。
- 术语表保存在应用数据中，而不是世界文件夹里。翻译后修改术语表时，应用前只会重新翻译受影响的句子。

### 提供商与模型

- 配置 OpenAI、Gemini、Anthropic、OpenRouter、Comet 或自定义 endpoint（OpenAI/Anthropic 兼容 wire format）。可用模型取决于提供商和账户。
- 查询模型列表；价格已知时显示每百万 token 的价格。OpenRouter 的公开 catalog 会自动获取，查询不会保存设置。
- 将 OpenRouter 或 Gemini 推理设为模型默认值、关闭或某个受支持的强度。必须使用推理的模型无法关闭推理，不支持的强度无法保存。
- 在首次运行的设置助手中完成配置：选择提供商（附密钥页面链接）、粘贴密钥并自动检查连接（输入的密钥只用于那一次请求，保存前不会存储）、选择带价格的推荐模型，并设置目标语言和文体。
- 设置目标语言和文体预设（标准、亲切、正式、礼貌、故事风或自定义系统提示词），并添加额外指示。文体摘要助手会单独发起 AI 请求，可能产生费用。
- 当 catalog 中没有某个模型的价格时，可以自行输入输入价格和输出价格，费用估算会使用它们。
- 设置分为“翻译”“扫描范围”“高级”“应用”四个标签页；保存栏只在有需要保存的更改时出现。文件/键规则和已保存的手动翻译使用标签和表格编辑器。

### 检查、应用与费用控制

- 默认情况下，写入世界前会先打开译文检查页面。可以修改任意一行（会验证格式代码和占位符），用易懂的语言查看句子失败的原因，并只重新翻译失败的句子。
- 应用之后，“编辑译文”会恢复该任务的备份，并重新应用已保存的译文和你的修改；不会发送 AI 请求，并设计为中途中断也能恢复。
- 可以设置 USD 费用上限：预计最高费用超过上限时会给出警告，运行中达到上限会在写入前停止，之后可以继续。估算包含推理和术语表的余量。
- 进度页面显示剩余时间和最近翻译；长时间任务在后台完成时，可按设置发送系统通知。

### 安全写入与恢复

- 写入前会把将要修改的文件保存到已验证的备份中；恢复前的状态会保留为 recovery snapshot。
- 如果扫描后世界发生变化，指纹就不再匹配，应用会拒绝写入。游戏或服务器正在使用世界时，`session.lock` 冲突会停止写入。
- 指向所选世界之外的路径以及符号链接资源包，会在读取或发送到 API 之前被拦截。
- 取消或失败时，已经翻译的字符串会保留，重试只会请求剩余内容。提供商故障会让世界文件保持未修改状态。
- 无法读取的区块会原样保留，并在结果中报告。

### 资源包 ZIP

- 可以选择翻译世界内 `resources.zip` 和最多 16 个由你明确选择的外部 ZIP 中的语言文件。
- 外部 ZIP 在修改前也会备份；恢复时需要在设置中再次选择同一个 ZIP。文件夹形式的资源包目前不支持。

### 密钥与隐私

- 桌面端 credential 默认保存于**本地加密 SQLite vault 和独立密钥文件**。仅当前会话和 OS 密钥链模式为可选项。
- 已保存的密钥不会再次显示在 UI 中，也不会写入公开设置 JSON 或世界备份。
- 只有在你按下导入按钮时才会访问 OS 密钥链；应用启动时不会自动读取。

### 桌面体验

- 使用 Tauri 2 + Svelte 5 外壳和 Python 核心；桌面应用不会为 UI 打开 localhost 服务器。
- UI 支持韩语、英语、日语和简体中文，并支持系统、浅色和深色主题。“查看”菜单可以将界面缩放到 75%–200%。
- 提供桌面应用式体验：统一的 macOS 标题栏；固定的侧边栏和工具栏，仅内容区域滚动；菜单快捷键（`Cmd/Ctrl+O` 打开世界、`Cmd+,` 设置、`Cmd/Ctrl+F` 查找）；将世界文件夹拖入窗口；显示来自 Minecraft saves 文件夹的世界列表和图标；Dock/任务栏进度；任务运行时的退出保护；有未保存设置时关闭前的确认；记住窗口大小和位置。
- 命令方块：`tellraw`/`title` 文本同时读取 JSON 和 Java 1.21.5+ SNBT；只按原来的引号形式改写变更的字符串，无法读取的命令会保留并报告。
- 提供使用同一核心的 CLI。桌面应用保存的密钥与 CLI 的 keyring/环境变量不会自动共享。

## 使用方法

1. 关闭 Minecraft 或服务器，并创建**世界的独立副本**。
2. 首次运行时按设置助手（或在设置中）选择提供商、模型和目标语言，并添加翻译指示。使用 AI 翻译时，输入并保存你自己的 API 密钥。
3. 在**选择世界 → 扫描**中打开副本，查看支持范围和警告。
4. 在**检查**中排除字符串并填写手动译文。
5. 在**执行**中确认目标、推理、外部传输、预计费用和费用上限，然后开始。
6. 在译文检查中修改译文、重新翻译失败的句子，然后应用到世界。应用之后仍可编辑译文。
7. 查看**结果**并在游戏中确认文本。需要撤销时，从**备份管理**恢复。

费用估算可能与实际账单不同。估算无法反映重试、账户/路由差异和提供商统计延迟，因此也请查看提供商后台。[使用指南](user-guide.zh.md)对设置、恢复和 CLI 用法有更详细的说明。

### 从源码运行

目前以开发构建为参考；没有签名安装包，也不是所有 OS 都已验证。从源码运行需要 Python 3.12、Node.js 22.12 或更高版本、pnpm 12.6.0、Rust toolchain 以及 [Tauri 平台准备项](https://v2.tauri.app/start/prerequisites/)。

```bash
git clone https://github.com/kim0040/PomiTranslate.git
cd PomiTranslate
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt pyinstaller==6.16.0
pnpm install --frozen-lockfile
pnpm desktop:dev
```

上面的激活命令适用于 macOS/Linux。Windows 命令、toolchain 版本和打包方式见[开发指南（韩语）](development.md)，贡献步骤见 [CONTRIBUTING.md（韩语）](../CONTRIBUTING.md)。打包方案包含 Python sidecar，但 clean-machine 安装尚未验证。

## 支持范围

PomiTranslate 可以处理告示牌、书页和书名（包括过滤书名）、实体和方块名称、物品名称和物品描述、文本显示实体、命令文本组件以及 ZIP 资源包语言文件。已验证的压缩格式为 gzip、zlib、无压缩、LZ4 和外部 `.mcc`。支持范围以**合成 fixture** 为依据：某一行通过只表示该数据形状能正确读写，不表示每个 Minecraft 版本、模组或世界中的所有文本都能被找到。

扫描范围包括每个维度的 `region` 和 `entities` 文件夹、世界内的 `resources.zip`，以及桌面端明确选择的外部 ZIP。数据包、scoreboard、command storage、`level.dat` 文本、player data 和文件夹形式的资源包目前不在范围内。Bedrock、`.mcr`、`.linear` 和未知压缩格式绝不会被写入。[支持表（韩语）](support-matrix.md)
