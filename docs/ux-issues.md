## 검증 공백 (기능은 구현됨, 확인 안 함)

아래는 browser fixture(합성 데이터)와 단위 테스트로만 확인했다. 코드상 구현은 끝났지만 실제 창·OS·제공사에서 동작을 본 적이 없다. UX-NATIVE-01에서 함께 본다.

- macOS/Windows 실제 창: 창 X·⌘Q 시 저장하지 않은 설정·설정 도우미 입력·번역 검토 수정본 확인 dialog, 작업 중 종료 보호의 마지막 경계, 10초 무응답 fallback.
- OS 알림: 첫 알림 때만 권한 요청, 허용/거부, 실제 전달, 창이 앞에 있을 때와 설정을 끈 때 억제.
- 창 크기·위치·최대화 복원, 모니터 제거·배율 변경, 전체 화면에서 일반 크기를 덮어쓰지 않는지.
- 실제 제공사: 설정 도우미의 연결 확인(저장하지 않은 키로 모델 목록 조회), 용어집 프롬프트·불일치 재요청의 실제 비용, 비용 한도 정지 시점, 실패 코드 분류(시간 초과·인증·한도 등)의 실제 응답 대응.
- 소개 화면(`docs/images/locales/*`)은 이번 개편 뒤 다시 캡처했는지 [현지화 관리](localization.md)와 manifest를 따른다.
