# PomiTranslate ユーザーガイド

[English](user-guide.en.md) | [한국어](user-guide.md) | 日本語 | [简体中文](user-guide.zh.md)

## はじめに

現在は開発中のアプリです。macOS Apple Silicon の開発アプリで主要な流れを確認していますが、正式な署名付き配布やすべての OS での検証は完了していません。先に[実行準備（韓国語）](development.md)と[対応範囲（韓国語）](support-matrix.md)を確認してください。

Minecraft またはサーバーを終了し、ワールドの**独立したコピー**を作ってください。アプリの自動バックアップは、別に保管したコピーの代わりにはなりません。元のマップやリソースパックの権利は制作者に帰属し、MIT ソフトウェアライセンスはマップの再配布を許可するものではありません。

![大切なワールドは、アプリの外にも独立したコピーを保管してください](../assets/illustrations/docs/doc_backup_first_ja_v1.png)

## 1. 設定

### 初回起動: 設定アシスタント

![選択した原文と翻訳指示はプロバイダーに送信され、AI API の利用料が発生する場合があります](../assets/illustrations/docs/doc_api_notice_ja_v1.png)

初回起動では、案内への同意に続いて**設定アシスタント**が開きます。「あとで」を選んでもスキャンと候補確認はできます。設定が必要なのは翻訳を開始する前だけです。ヘルプの「設定アシスタントを開く」からいつでも開き直せます。

1. **AIプロバイダーを選ぶ:** OpenRouter、Gemini、OpenAI、Anthropic、Comet から選びます。各カードの「キー発行ページを開く」で、そのプロバイダーのキー発行ページを既定のブラウザーで開きます。OpenAI または Anthropic 互換のサーバーを直接指定する場合は「詳細: カスタム指定」を選びます。
2. **API キー:** キーを貼り付けると、すぐに接続を確認し、利用できるモデル数を表示します。この確認では入力したキーをモデル一覧のリクエスト 1 回にだけ使い、最後の手順で保存するまで保存しません。このプロバイダーのキーがすでに保存されている場合は、新しいキーを入力しなくても保存済みのキーを使います。
3. **モデルを選ぶ:** おすすめのモデル（最も安価な高速モデル）があらかじめ選ばれ、モデルごとに 100 万トークンあたりの入力・出力単価を表示します。価格情報がないモデルはその旨を表示します。
4. **翻訳の言語と文体:** 翻訳先言語を一覧から選ぶか直接入力し、文体を選びます。
5. **完了:** 「保存して完了」を押すと、プロバイダー、モデル、言語、文体、入力したキーがまとめて保存されます。途中で閉じた場合は何も保存されず、設定を続けるか破棄するかを確認します。

### 設定画面の構成

設定は 4 つのタブに分かれています。タブ名の横の数字はそのタブの未保存の変更数で、エラーがあるタブには印が付きます。画面下部の保存領域は、**保存が必要な変更があるときだけ**表示され、保存または変更の取り消しができます。表示言語、表示モード、通知の設定のように、選ぶとすぐ反映される項目には保存は不要です。各区分の「この区分を既定値に戻す」は、その区分だけを初期値に戻します。

### 翻訳タブ

- **プロバイダー:** OpenAI、Gemini、Anthropic、OpenRouter、Comet、カスタム endpoint から選びます。カスタム endpoint の URL と wire format（OpenAI/Anthropic 互換）は「詳細」タブで指定します。
- **API キー:** AI 翻訳に使うご自身のキーを入力して保存します。「接続を確認」は、入力したキー（または保存済みのキー）でプロバイダーにモデル一覧を問い合わせて接続を確認します。入力したキーは保存しません。保存後はキーの値を表示せず、保存状態と保存方式だけを示します。キーは変更または削除でき、保存方式は「キー管理とセキュリティ」で選びます。
- **モデル:** 一覧から選ぶか、モデル ID を直接入力します。一覧はおすすめとすべてに分かれ、検索でき、翻訳に向かないモデルは既定で非表示になります。価格情報がある場合は 100 万トークンあたりの入力・出力単価を表示します。
- **モデル情報の照会:** OpenRouter は公開カタログを自動で照会し、手動で更新することもできます。この照会は設定を保存せず、API キーやワールド内のテキストも送信しません。他のプロバイダーでは入力済みまたは保存済みのキーが必要です。キャッシュの表示、照会失敗、モデル未発見は画面で区別されます。
- **単価を入力:** 選択したモデルの単価がカタログにないときに表示されます。入力・出力単価（USD / 100 万トークン、0〜1,000、両方必須）を入力すると、そのモデルの費用推定に使い、実行画面に「ユーザー入力の単価に基づく見積もり」と表示します。
- **推論（OpenRouter・Gemini）:** モデルのデフォルト、推論を無効化、設定を指定、から選びます。モデル情報を確認できた場合は対応している強度だけを表示し、推論が必須のモデルでは無効にできません。Gemini は「モデル一覧を読み込む」を一度実行すると、モデルの thinking 対応を確認できます。Gemini 3 系では thinking が既定で有効なため、短い翻訳でも多くの思考トークン（出力として課金）が使われることがあります。翻訳では**推論を無効化**することをおすすめします。一部の新しいモデル（3.7/3.8 flash、pro、<code>gemini-flash-latest</code>）では完全に無効にできず、アプリが許可される最も低い段階に自動調整します。思考トークンは結果画面の出力トークンに含めて表示します。
- **使用量の確認（OpenRouter）:** 保存済みキーの累計使用クレジットを照会します。翻訳リクエストを送ったり、設定を保存したりしません。同じキーを使う別の処理や集計の遅れにより、照会前後の差が今回の費用と一致しない場合があります。
- **翻訳先言語・文体:** 翻訳先言語は一覧から選ぶか直接入力します（UI 言語とは別の設定）。文体は標準・自然（推奨）、親しみやすい・会話調、フォーマル・明快、丁寧語、物語風、カスタムシステムプロンプトから選び、「固有名詞は原文のまま残す」のような**追加指示**を加えられます。「AIで指示を整える」は短いメモを AI で詳しくする機能です。選択したプロバイダーへ別のリクエストを送り、費用が発生する場合があるため、内容を確認してから実行してください。
- **翻訳の確認と費用上限:** この 2 つの設定は[翻訳を実行して結果を確認](#4-翻訳を実行して結果を確認)で説明します。既定では「ワールドに書き込む前に翻訳を確認」がオン、費用上限は 0（制限なし）です。
- **用語集:** すべてのワールドに適用する用語集をこの区分で編集します。詳しくは[用語集](#用語集)を参照してください。

### スキャン範囲タブ

- **ワールド内のテキスト種類:** 看板、本のページ、本のタイトル、フィルタリングされた本のタイトル、エンティティ名・ブロック名、アイテム名、アイテム説明、テキストディスプレイ、コマンドテキストコンポーネントから調べる種類を選びます。おすすめ範囲、ストーリー向けプリセット、すべて選択・解除を使えます。コマンドのように見える通常の文字列を除外する設定もあります。
- **翻訳先言語で書かれたテキストをスキップ:** 再翻訳の費用と時間を減らします。
- **ZIP リソースパック:** ワールド内の <code>resources.zip</code> と、明示的に選択した外部 ZIP（最大 16 個）を一緒に翻訳するかを設定します。対象範囲を変更した場合は、もう一度スキャンしてください。
- **保存する手動翻訳:** すべてのワールドに適用する原文→訳文を表で編集します。検索、「行を追加」、行ごとのエラー表示に対応し、「JSONを読み込む／書き出す」でファイルとやり取りできます。原文が完全に一致する場合にだけ使われ、API は呼び出しません。候補確認画面で入力した訳文が優先されます。最大 5,000 組、各 32,000 文字、合計 1 MB です。

![翻訳候補と対象範囲は、ファイルを変更する前にスキャンして確認できます](../assets/illustrations/docs/doc_scan_first_ja_v1.png)

### 詳細タブ

- **速度・リクエスト上限:** 同時リクエスト数、1 リクエストあたりの文章数、分あたりのリクエスト（RPM）とトークン（TPM）の上限、タイムアウト、最大再試行数、生成の多様性（Temperature）を設定します。値を 0 にすると、その上限を設けません。ファイル書き込みの再試行数と、「ファイルエラーの後も他のファイルを処理する」設定も選びます。続行した場合、結果は一部完了として表示されます。
- **ファイルと翻訳キーの規則:** 追加する region フォルダー、除外するファイルパターン、翻訳キーの接頭辞を入力チップで追加・削除します。通常は変更する必要はありません。
- **カスタムエンドポイント:** カスタムのプロバイダーを選んだときだけ表示され、アドレスと通信規格（OpenAI/Anthropic 互換）を指定します。
- **設定のインポート・エクスポート:** PomiTranslate または旧 Web UI の JSON 設定、あるいは <code>translate.py</code> を取り込みます。Python ファイルは実行せず、公開された文字列定数だけを読み取ります。API キー、ワールドパス、UI 言語、外部 ZIP のパスは取り込まず、エクスポートしたファイルにもキーは含まれません。取り込んだ値は編集画面に読み込まれるだけで、保存すると適用されます。

### アプリタブ

- **表示言語:** 韓国語、英語、日本語、簡体字中国語から選びます。翻訳先言語とは別で、選ぶとすぐ反映されます。
- **表示モード:** プレビュー（システム・ライト・ダーク）、またはメニューバーの「表示 → 表示モード」で選びます。選択すると画面、ウィンドウの枠、メニューのチェックにすぐ反映され、保存ボタンを押さなくても設定ファイルに保存されます。「システム」は OS のライト・ダーク設定に従い、アプリを開いたまま OS の設定を変えた場合も切り替わります。起動時の背景にも保存済みモードを適用する実装はありますが、最新の macOS/Windows native 起動確認は未完了です。
- **作業完了時に通知:** 既定でオンです。アプリのウィンドウが背面にあるとき、10 秒以上かかったスキャン・翻訳・復元が終わると OS の通知を送ります。通知の許可は最初の通知を送るときに一度だけ求め、許可されなくても作業には影響しません。通知にはワールド名、件数、状態だけが含まれ、原文・訳文・パス・キーは含まれません。
- **アップデート:** 新しいバージョンを確認します。1 日 1 回の自動確認（無効にできます）は GitHub から最新バージョン情報だけを取得します。署名検証キーが含まれる配布版はアプリ内でインストールして再起動する設計です。それ以外のビルドではダウンロードページを開きます。スキャン、翻訳、復元中はインストールしません。設定、保存済みキー、バックアップはアップデート後も保持する設計ですが、署名付きアップデートの native インストール検証はまだ完了していません。
- **データの保存場所:** 設定・作業・バックアップのフォルダーと、暗号化キーのフォルダーのパスを確認して開けます。アプリ更新やキャッシュ整理ツールはこれらのフォルダーを削除しません。詳しくは[アップデートとデータ保持（韓国語）](updates-and-data.md)を参照してください。
- **初期化:** 2 回確認した後、すべての設定、最近使ったワールド、再開可能な作業、モデル一覧を削除してアプリを再起動します（選択すれば保存済み API キーも削除します）。**ワールドのバックアップと元のワールドは削除しません。**

### 拡大・メニュー・ウィンドウ

- **拡大:** 「表示」メニューで 75〜200% に拡大できます。<code>Cmd/Ctrl+0</code> は 100%、<code>Cmd/Ctrl+2</code> は 200% です。
- **メニューとショートカット:** 「ファイル → ワールドを開く」（<code>Cmd/Ctrl+O</code>）、「設定」（macOS のアプリメニューでは <code>Cmd+,</code>、Windows/Linux では「ファイル」メニュー）、「編集 → 検索」（<code>Cmd/Ctrl+F</code>、候補確認画面の検索欄へ移動）、「ヘルプ → ヘルプ・開始ガイド・ショートカット・オープンソースライセンス・問題を報告」を使います。アップデートの確認は macOS ではアプリメニュー、その他では「ヘルプ」メニューにあります。Web リンクはアプリ内ではなく既定のブラウザーで開きます。
- **ウィンドウ:** ウィンドウのサイズと位置を記憶し、次回起動時に復元します（保存した位置がどの画面にも入らない場合は中央に戻します）。長いスキャンや翻訳の実行中は Dock（macOS）やタスクバー（Windows）に進捗を表示します。ウィンドウが背面にあるときに処理が終わるとアイコンで知らせます。作業中はウィンドウを閉じたり、<code>Cmd+Q</code> でアプリを終了したりできず、その理由が表示されます。
- **終了時の確認:** 未保存の設定、終えていない設定アシスタントの入力、未保存の用語集の変更、まだ適用していない翻訳確認の修正がある場合は、ウィンドウを閉じる前やアプリを終了する前に、保存・破棄・編集を続ける、のどれかを選びます。別の画面へ移動するときも同じ確認が表示されます。
- **情報画面:** バージョン、検証済み形式と未対応形式、システム診断情報、リポジトリ・ライセンス・問い合わせ先、Minecraft に関する非公式製品表示の原文を確認できます。「オープンソースライセンス」では同梱コンポーネントのライセンス全文を表示します（ヘルプメニューからも開けます）。
- **ヘルプと開始ガイド:** サイドバーの「ヘルプ」、<code>F1</code>、または macOS の <code>Cmd+?</code> から、クイックスタート、よくある質問、ショートカット、API キー取得ページ、問題報告を開けます。初回起動時は案内への同意と設定アシスタントの後に 4 段階の開始ガイドが一度表示されます。「ヘルプ → 開始ガイド」から再表示できます。

## 2. ワールドを選択してスキャン

コピーしたワールドフォルダー（<code>level.dat</code> を含む）またはサーバーのルートフォルダーを選びます。「ワールドフォルダーを開く」、フォルダーまたは <code>level.dat</code> をウィンドウへドラッグ＆ドロップ、または「Minecraft ワールド」一覧から選ぶ、3 つの方法があります。一覧は公式ランチャーと Prism/MultiMC（macOS・Linux）、CurseForge（Windows）の saves フォルダーを読み取り専用で確認し、ワールドのアイコン、名前、最終プレイ日時を表示します。アプリはワールドを内部にコピーせず、直接読み取ります。元のワールドではなくコピーを選んでください。画面ではディメンション、データ形式（DataVersion）、ワールド内蔵リソースパック、保持中のバックアップ数を確認できます。

Bedrock、旧式の <code>.mcr</code>、<code>.linear</code>、ゲームやサーバーが使用中のワールド、読み書き権限のないフォルダー、選択したワールドの外を指すパスは開始前にブロックされます。

ワールド画面の「スキャンを開始」を選ぶと、すぐにスキャンが始まります。「ワールドスキャン」は翻訳 API を呼び出さず、ワールドファイルも変更せずに候補を集めます。結果では重複を除いた文字列数と出現場所の数を分けて確認し、スキャン範囲と除外一覧も見てください。読み取れないチャンクは元のまま保持され、警告が表示されます。未知の形式、圧縮方式、読み取りエラーを対応済みと見なさないでください。

コマンドブロックの <code>tellraw</code> / <code>title</code> は、従来の JSON 形式と Java 1.21.5 以降の SNBT 形式（<code>{text:'Hello',color:gold}</code>）を読み取ります。変更した文字列だけを元の引用符の形式で書き戻します。解釈できないコマンドは変更せず、「形式を解釈できないコマンド N 件」という警告を表示します。スキャン画面の「最新のスキャンレポートをエクスポート」から結果を JSON ファイルに保存できます。

スキャン画面上部の「このワールドの最近の作業」では、最近のスキャン（候補数）と最近の翻訳（状態、翻訳済み・失敗した文の数）を確認できます。続行できる作業がある場合は「作業を続ける」カードが表示されます。

![未対応の圧縮形式を含むリージョンは、書き込み前に処理を止め、その領域を変更しません](../assets/illustrations/docs/doc_unsupported_ja_v1.png)

## 3. 翻訳候補を確認

検索（文字列または場所）、並べ替え（ワールド順・原文順・出現頻度順・種類別）、テキストの種類と状態のフィルターで候補を探します。項目を選ぶと原文と使用場所が表示され、訳文を直接入力できます。対象から外すと、その候補は翻訳されません。現在のフィルターに一致する項目をまとめて対象にしたり、除外したりすることもでき、一括変更の直後に表示される「元に戻す」で取り消せます。

- **使用場所:** ディメンション名と座標（x・y・z）など、読みやすい形で表示します。座標のある場所では「テレポートコマンドをコピー」で、ゲーム内でその場所へ移動するコマンドをコピーできます（クリップボードにコピーするだけで、ワールドには何も書き込みません）。
- **候補の操作メニュー:** 一覧の行で右クリック（またはキーボードのメニューキー、<code>Shift+F10</code>）すると、翻訳対象に含める／除外する、翻訳を手入力、原文をコピーを選べます。

<code>§</code> 書式コードや <code>%s</code>、<code>{0}</code> のようなプレースホルダーは、ゲーム内でもそのまま表示されるよう保持してください。AI の訳文で必要な記号が抜けたり、原文にない記号が加わったりした場合（例: 色コードが増えて別の単語の色が変わる場合）、その文は原文のまま残し、結果に「書式保護のため原文を保持」と表示します。同じ数の書式コードが別の単語の隣へ移動した訳文は許可されます。

現在の候補は、同じ原文を複数の使用場所にまとめて適用する単位です。場所ごとの訳し分けと translation memory はまだ対応しておらず、今後の作業です。すべての文を手入力すれば、AI 翻訳 API のリクエストなしで適用できます。

### 用語集

固有名詞などの訳し方を固定するルールを決めます。たとえば `Elder Mira` を常に決まった名前に訳したり、`Nether` を訳さないようにしたりできます。

- **範囲:** 「すべてのワールド」の用語集は設定 → 翻訳タブで、「このワールドのみ」の用語集は候補確認画面の「このワールドの用語集」で編集します。両方に同じ原文の用語がある場合は、ワールドの用語が優先されます。候補の詳細で「用語集に追加」を選ぶと、選択した文をそのまま用語として追加できます。
- **方式:** 「翻訳する」（固定訳を指定）または「翻訳しない」（原文のまま）。メモと、大文字・小文字を区別するかどうかを設定できます。範囲ごとに最大 2,000 件で、原文の用語は 200 文字、訳とメモは 500 文字までです。`§a` のような書式コードは使えません。
- **インポート・エクスポート:** JSON または CSV（列: `source`、`target`、`mode`、`note`、`caseSensitive`）でやり取りします。
- **使われ方:** 翻訳リクエストには、そのまとまりの原文に含まれる用語だけを入れます。AI がルールと違う訳を返した場合は、アプリが同じ文をリマインダー付きでもう一度依頼し、それでも違う場合は確認画面で「用語の確認」と表示します。この追加リクエストの費用は予想費用の範囲に含まれます。
- **翻訳後に用語集を変更した場合:** 適用する前に影響を受ける文を知らせ、「影響を受ける文を再翻訳」を促します。ほかの翻訳とスキャン結果は保持されます。
- **保存場所:** 用語集はワールドフォルダーではなくアプリのデータに保存されます。[データとキーの取り扱い](privacy.ja.md)を参照してください。

## 4. 翻訳を実行して結果を確認

### 実行前の確認

「翻訳実行」画面では、対象ワールド、言語、プロバイダーとモデル、送信する文字列数、手動翻訳の項目数、推定リクエスト数、推定費用、安全バックアップの有無を確認します。推定費用は下限〜上限の範囲で表示し、推論トークンと、用語集のリマインダー用の追加リクエストの余裕分を含みます。それでも請求額の上限ではありません。再試行、アカウントやルーティングの違い、プロバイダー側の集計遅延があるため、実際のダッシュボードも確認してください。手動翻訳だけを適用するモードでは API リクエストは発生しません。

**費用の上限（USD）** はこの画面、または設定 → 翻訳タブで決めます。0 は制限なしです。推定の最大費用が上限を超える場合は、開始前に警告が表示され、「設定を変更」または「このまま開始」を選べます。「このまま開始」でも、実行中は上限がそのまま適用されます。開始後に実際の費用が上限に達すると、翻訳を止め、ワールドには何も書き込みません。ここまでの翻訳は保持されるため、上限を変更して続行すると、残りの文だけをリクエストします。結果画面の「今回だけ上限なしで続行」はもう一度確認したうえで実行され、その 1 回の実行にだけ適用され、保存済みの上限は変わりません。

### 進行状況

進行画面には、段階（テキスト収集 → AI 翻訳 → ワールドファイルの保存）、残り時間の目安、リクエスト数、失敗件数、「最近の翻訳」が表示されます。実行中にキャンセルを依頼すると、処理を協調的に停止します。checkpoint を使って残りの翻訳を再開できます。キャンセルや失敗が必ず「ファイル変更数 0」を意味するとは限らないため、完了結果の変更数、エラー、使用量を確認してください。すでにファイルへ書き込まれている場合は、バックアップからの復元を検討してください。再開設定やファイルのフィンガープリントが変わった場合は再スキャンが必要になることがあります。処理中はウィンドウを閉じることもアプリを終了することもできません。

### 翻訳を確認してから適用

設定の「ワールドに書き込む前に翻訳を確認」（または実行画面の「適用前に翻訳結果を確認する」）がオンの場合（既定）、翻訳が終わった後、ワールドへ書き込む前に「翻訳結果の確認」画面が開きます。この時点ではワールドに何も書き込まれていません。

- 表で原文・訳文を検索し、翻訳済み・失敗・原文維持・修正済み・用語の確認が必要、で絞り込めます。
- 行を選んで訳文を直接修正できます。<code>§</code> 書式コードや <code>%s</code>、<code>{名前}</code> のようなプレースホルダーが原文と異なる場合はエラーとして表示し、その文は適用しません。空の訳文や、ワールドに書き込めない文字を含む訳文も同様です。「AIの翻訳に戻す」で修正を破棄できます。
- 失敗した文は理由をわかりやすい文章で表示します（応答の遅延、キーの拒否、リクエスト制限、残高不足、形式の不一致、プロバイダーの安全フィルター、ネットワークエラーなど）。「失敗した N 件を翻訳し直す」はその文だけを再リクエストし、推定費用も表示します。
- 「ワールドに適用」を押すと確認ダイアログが開き、適用前に変更されるファイルをバックアップして検証します。翻訳できなかった文は原文のまま残ります。確認中の作業は保存されているため、いったん離れて後で戻り、続けて適用できます。

確認をオフにすると、翻訳が終わりしだい適用されます。この場合は、一部の文が失敗したときの動作（安全に停止／完了した文だけを適用）を実行画面で選びます。

### 適用後の訳文修正

完了した結果画面の「翻訳文を修正」から、すでに適用した翻訳を修正できます。同じ確認画面で文を修正し、「修正 N 件を再適用」を押すと、アプリは ① 現在のワールドの状態を復旧用スナップショットとして保管し、② 翻訳前に作成したバックアップでワールドを復元し、③ 保存済みの翻訳と修正内容を新しいバックアップとともに適用します。この間に AI へのリクエストは送らないため、追加の費用はかかりません。復旧用スナップショットと進行記録を残すので、途中でアプリが止まっても、再起動後に中断した作業と復旧ポイントが残っています。Minecraft を終了した状態で行ってください。適用後にワールドを自分で変更した場合は再適用できないため、ワールドを再スキャンしてください。

### 結果

結果画面では次の状態を区別して表示します。

| 状態 | 意味 |
| --- | --- |
| 完了 | すべての翻訳を適用しました。 |
| 一部完了 | 翻訳できなかった文は原文のまま残しました。 |
| 再試行が必要 | ワールドファイルは変更されていません。翻訳済みの文は保存されているため、残りを続けて翻訳できます。 |
| 費用上限で停止 | 上限に達して書き込む前に止まりました。翻訳済みの文は保持され、続きから翻訳できます。 |
| 失敗 | 変更ファイル数とエラーを確認し、必要に応じてバックアップから復元します。 |
| キャンセル | 翻訳済みの文は保存されています。いつでも作業を再開できます。 |
| ワールド使用中 | ゲームやサーバーを終了してから再試行してください。 |
| ワールドが変更された | スキャン後にファイルが変わったため書き込みを停止しました。再スキャンしてください。 |
| 未対応形式 | ワールドファイルは変更されていません。 |

結果には、訳文準備済み・翻訳完了・原文維持（固有名詞など）・翻訳失敗・書式保護により原文を維持した文の数、変更ファイル数、API リクエスト数、使用トークン、実際に報告された費用が表示されます。翻訳例、失敗した文（理由付き）、書式保護で原文を維持した文も確認でき、「すべての翻訳を見る」ですべての翻訳を開けます。

ゲーム内でテキストとコマンドの動作を確かめてください。翻訳は不正確な場合があります。「最新の翻訳レポートをエクスポート」から結果を JSON ファイルに保存できます。レポートにはワールドのパスと原文・訳文が含まれることがあるため、共有する前に内容を確認してください。

## 5. 復元

Minecraft とサーバーを終了した状態で「バックアップ管理」を開きます。ワールドと復元する時点を確認し、案内を読んでから実行してください。復元の直前に現在のファイルを保存する recovery snapshot が作成されます。復元すると、そのファイルについてバックアップ後に行った編集やゲーム内の進行が巻き戻る場合があります。

バックアップには、翻訳前に作成する自動バックアップと、復元直前の安全スナップショットがあります。アプリのデータ保存領域、または旧バージョンではワールドフォルダー内にある場合があります。一覧はバックアップごとに簡潔なカードで表示され、バックアップの種類、作成日時、ファイル数、整合性の検証状態を確認でき、バックアップ ID をコピーできます。外部 ZIP も翻訳した場合は、復元時に設定で同じ ZIP をもう一度選択してください。

デスクトップ版では自動バックアップと checkpoint の場所をアプリが管理し、バックアップの無効化、接尾辞、任意のパスを指定する設定はありません。翻訳で新しい大容量チャンクファイルが作成された場合も、復元前の状態を保存して、翻訳前のファイル構成に戻します。この新しいバックアップは最新版のアプリで復元してください。従来の Legacy バックアップも引き続き検出して復元できます。

未検証のバックアップ、パスエラー、破損の警告を無視しないでください。バックアップはすべてのストレージ故障や外部からの変更に対する復旧を保証するものではありません。

## CLI

CLI は同じ Python コアを使いますが、デスクトップ版とは vault と認証情報の保存経路が異なります。従来の CLI の keyring・環境変数との互換性は維持されます。秘密情報をコマンド引数、平文の設定、Git に記録せず、既存の OS keyring を使ってください。デスクトップアプリに保存したキーは CLI と自動共有されません。

~~~bash
# --report-path にはワールド外の一時パスを指定してください。
.venv/bin/python mc_world_translator.py \
  --world-dir "/path/to/World-copy" \
  --dry-run \
  --report-path "/tmp/pomi-scan-report.json"

.venv/bin/python mc_world_translator.py --help
~~~

主なオプション:

| オプション | 説明 |
| --- | --- |
| <code>--dry-run</code> | スキャンだけを行い、API 呼び出しやファイル書き込みをしません。 |
| <code>--expect-fingerprint</code> | スキャンレポートのフィンガープリントとワールドが異なる場合、書き込みを拒否します。 |
| <code>--resume</code> | 保存済み checkpoint から残りの翻訳を再開します。 |
| <code>--restore-backup</code> | 検証済みの最新バックアップから復元します。 |
| <code>--no-backup</code> | バックアップなしで実行します。おすすめしません。 |
| <code>--resource-pack-zip</code> | 翻訳する ZIP リソースパックのパスです。複数指定できます。 |
| <code>--enable-resource-pack-translation</code> / <code>--disable-resource-pack-translation</code> | 設定に関係なく、ZIP 翻訳を有効または無効にします。 |
| <code>--list-models</code> | 選択したプロバイダーのモデル一覧を表示して終了します。 |
| <code>--enhance-style-brief</code> | 短い文体メモを AI で詳しくします。追加費用が発生する場合があります。 |
| <code>--print-notices</code> | 初回実行時の安全に関する案内を表示します。 |
| <code>--provider</code>、<code>--model</code>、<code>--base-url</code>、<code>--wire-format</code>、<code>--api-key</code> | プロバイダー、モデル、endpoint、wire format、キーを指定します。 |
| <code>--target-language</code>、<code>--style-preset</code>、<code>--style-prompt</code>、<code>--custom-system-prompt</code> | 翻訳先言語と文体を指定します。 |
| <code>--batch-size</code>、<code>--temperature</code> | 1 回のリクエストにまとめる文数と生成の多様性を指定します。 |
| <code>--config</code>、<code>--data-dir</code>、<code>--report-path</code> | 設定ファイル、データフォルダー、レポートの保存先を指定します。 |

上記は macOS/Linux の例です。Windows では <code>.venv\Scripts\python.exe</code> を使います。実際に実行するとファイル書き込みや API 利用料が発生する場合があります。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| アプリを準備できない | コアが 30 秒以内に起動せず、最近のワールドやバックアップの初期情報が 60 秒以内に読み込めない場合は停止します。「再試行」を選んでください。繰り返し発生する場合はアプリを再起動し、最近使ったワールドの保存先ドライブが接続されているか確認します。この制限は実行中の長い翻訳や復元には適用されません。 |
| <code>AUTH_FAILED</code> | 設定で API キーを確認します。 |
| <code>NO_CREDIT</code> | プロバイダーのアカウント残高やクレジットを確認します。 |
| <code>RATE_LIMITED</code> | 少し待ってから再試行するか、同時リクエスト数を減らします。 |
| <code>MODEL_NOT_FOUND</code> | モデル ID を確認するか、「モデル一覧を読み込む」で再取得します。Gemini の旧別名 <code>flash</code> / <code>pro</code> は <code>gemini-flash-latest</code> / <code>gemini-pro-latest</code> に変更されています。 |
| Gemini の応答が遅い、または「output token limit」エラーが出る | thinking が有効なモデルです。設定で推論を無効にするか、<code>flash-lite</code> 系を選びます。 |
| <code>NETWORK_ERROR</code> | インターネット接続とプロバイダーの稼働状況を確認します。 |
| ワールドが使用中 | Minecraft とサーバーを完全に終了してから再試行します。 |
| 費用上限で翻訳が止まった | 翻訳済みの文は保持されています。上限を変更するか、結果画面の「今回だけ上限なしで続行」で、残りの文だけを続けて翻訳します。 |
| 「修正が必要な翻訳文があります」 | 表示された文の <code>§</code>・<code>%s</code>・<code>{名前}</code> などの書式コードを原文と同じに直すか、「AIの翻訳に戻す」を押してから、もう一度適用します。 |
| 用語の確認が必要 | 訳文が用語集のルールと異なります。訳文を直すか、用語集を確認します。そのまま適用することもできます。 |
| 適用後にワールドが変更されて再適用できない | 適用した後にワールドを変更した場合です。ワールドを再スキャンします。 |
| スキャン結果が古い | ワールドや設定が変わった場合は再スキャンします。 |
| 保存済みキーの状態を確認できない | キーを入力し直すか削除してから、もう一度保存します。 |
