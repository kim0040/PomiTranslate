# 설정 화면 두 부분 분리·모델 목록·dialog X (2026-10-23)

[알려진 UI/UX 문제](../ux-issues.md)의 U2·U5·U12·U18을 확인하고 고쳤다. native 창에서는 확인하지 않았다(UX-NATIVE-01).

| # | 결과 | 내용 |
| --- | --- | --- |
| U5 | 고침 | 환경 설정을 "번역"(제공사·키·모델·언어·범위·성능·설정 파일 가져오기/내보내기)과 "앱"(화면 모드·표시 언어·알림·업데이트·데이터·진단·초기화) 탭으로 나눴다. `role=tablist`, 방향키·Home·End, 선택 즉시 전환. 저장 막대와 저장됨/저장 안 됨 상태는 번역 탭에만 있고 앱 탭은 "바로 적용됩니다"를 보인다. 번역 탭에 저장하지 않은 변경이 있으면 앱 탭으로 옮기기 전에 기존 "저장하지 않은 설정" dialog가 저장·저장 안 함·계속 편집을 묻는다. 도움말 메뉴의 "업데이트 확인"은 앱 탭, 설정 메뉴·"모델 바꾸기"·인증 오류는 번역 탭으로 열린다. 구역 목록은 열린 탭의 구역만 보인다. |
| U2 | 고침 | 키를 저장한 직후(OpenRouter 제외) 저장된 키로 모델 목록을 한 번 자동 조회하고 "저장한 키로 모델 목록을 불러오는 중…"을 보인다. 실패해도 아무것도 막지 않으며 버튼으로 다시 시도한다. 키가 없을 때는 모델 칸에 "키를 저장하면 목록이 나타나며, 그 전에도 모델 ID를 입력할 수 있다"를 한 줄로 보인다. 입력한 ID가 불러온 목록에 없으면 막지 않는 경고를 보인다. 저장하지 않은 키를 보내는 새 IPC 경로는 없다. |
| U12 | 고침 | 선택지가 있는 dialog는 모서리 X를 숨긴다(`Dialog showClose={false}`; Escape는 그대로 안전한/취소 선택). 이미 적용돼 있던 저장 확인 외에 시작 안내, 용어집 "추가", 용어집 가져오기가 더해졌다. |
| U18 | 이미 해결 | 1000px 미만에서 단계 이름 대신 "n/5단계 · 현재 이름"을 보이고, 모든 단계 버튼은 접근 이름(`aria-label`)을 유지한다. `tests/browser/visual-design.spec.ts`가 840px에서 확인한다. |
