## 로컬 앱과 외부 전송

월드 선택·스캔·검토는 로컬에서 처리합니다. AI 번역을 실행하면 번역 대상으로 선택한 원문, 도착 언어와 번역 지시 등 요청 내용이 **선택한 API 제공사 또는 Custom endpoint**로 전송됩니다. 서버 이름·책·표지판 등에 개인정보가 있다면 번역 대상으로 보내지 않도록 검토하세요. 제공사의 보관·학습·삭제 정책은 해당 서비스의 정책을 따릅니다.

**업데이트 확인**은 GitHub(`github.com/kim0040/PomiTranslate`)의 최신 버전 정보(`latest.json`)만 받아 옵니다. 월드, 키, 사용 기록, 설치 식별자는 보내지 않으며, 환경 설정 → 업데이트에서 하루 한 번 자동 확인을 끌 수 있습니다. 도움말·정보 화면의 웹 링크는 정해진 주소(GitHub, minecraft.net, 제공사 키 발급 페이지, 문의 메일)만 기본 브라우저로 엽니다.

모델 지원 정보와 사용량 조회도 선택한 제공사로 네트워크 요청을 보냅니다. OpenRouter의 공개 모델 catalog 조회에는 키와 월드 텍스트를 보내지 않습니다. 사용량 조회·다른 제공사의 인증 요청에는 저장된 키를 사용합니다. 번역 지시문 다듬기는 별도의 AI 요청입니다.

**연결 확인**(설정 도우미의 키 입력 단계와 환경 설정 → 번역 탭의 연결 확인)은 선택한 제공사에 모델 목록을 요청합니다. 입력란에 입력한 키를 쓰는 경우 그 키는 이 한 번의 요청에만 사용하며, 저장 버튼(설정 도우미는 마지막 단계의 저장)을 누르기 전에는 저장하지 않습니다. 키를 입력하지 않으면 저장된 키를 사용합니다.

**용어집**은 월드 폴더가 아니라 앱 데이터에 저장합니다(모든 월드용은 설정 파일, 월드별 용어집은 앱 데이터의 별도 파일). 월드 파일에는 아무것도 쓰지 않으며, 번역 요청에는 그 묶음의 원문에 들어 있는 용어 항목만 선택한 제공사로 함께 전송합니다. 용어를 포함하지 않는 요청에는 용어집을 보내지 않습니다.

**완료 알림**은 운영체제 알림이며 외부로 전송하지 않습니다. 앱 창이 뒤에 있을 때 오래 걸린 작업이 끝나면 월드 이름과 개수·상태만 표시하고, 원문·번역문·경로·키는 담지 않습니다. 알림 권한은 첫 알림을 보낼 때 한 번 요청하며, 환경 설정 → 앱에서 끌 수 있습니다.

데스크톱 앱은 UI용 localhost 서버를 열지 않고 JSONL sidecar를 사용합니다. 개발 Vite 서버와 legacy Web UI는 별도이며 같은 실행 구조로 소개하지 않습니다.

## 저장하는 데이터

설정, 용어집, 최근 월드 경로, 창 크기·위치, 모델 cache, scan plan·checkpoint, 번역 보고서와 백업은 앱 데이터에 남을 수 있습니다. 적용을 마친 작업도 번역문 수정을 위해 번역문이 checkpoint에 남습니다. 경로·원문·번역문이 포함될 수 있으므로 이를 진단 자료나 공개 저장소에 그대로 올리지 마세요. 환경 설정 → 앱 탭의 **초기화**로 설정·최근 월드·이어서 할 작업·모델 목록과 (선택 시) 저장된 API 키를 지울 수 있습니다. 월드 백업은 초기화로 지우지 않으며, 지우려면 데이터 폴더를 직접 삭제합니다. 도움말의 **진단 정보 복사**와 진단 내보내기는 앱 버전·빌드·OS, 오류 코드, 요청 종류·소요 시간·결과 코드와 코어 진단 줄의 알려진 모양만 담습니다. 자유 텍스트(오류 메시지, 경로, 월드 이름·원문, 키)는 만들 때부터 넣지 않고 로컬 로그 파일에도 쓰지 않습니다. 암호화된 portable export는 제공하지 않습니다. 업데이트·청소 도구와 데이터의 관계는 [업데이트·데이터 보존](updates-and-data.md)을 따릅니다.

공개 Python 설정 경로는 macOS `~/Library/Application Support/PomiTranslate`, Windows `%APPDATA%/PomiTranslate`, Linux `$XDG_DATA_HOME/PomiTranslate` 또는 `~/.local/share/PomiTranslate`입니다. native vault는 Tauri app-data 경로의 `credentials/credentials.sqlite`와 `credential-key/master.key`를 사용합니다. 격리 Eval identifier는 별도 root를 사용하므로 일반 앱과 데이터를 혼용하지 않습니다.

## API 키

- 기본: **로컬 암호화 저장** — Rust SQLite + AES-256-GCM과 별도 설치별 key 파일.
- 선택: **세션 전용** — 재시작 후 다시 입력해야 합니다.
- 선택: **OS 키체인** — 사용자가 선택하거나 기존 키 가져오기를 실행할 때 접근합니다. startup에서 자동으로 기존 키를 읽어 가져오지 않습니다.

화면에는 저장 여부·방식만 표시하며 저장된 키 원문을 반환하지 않습니다. API 요청에 필요한 키는 Rust가 sidecar stdin으로 전달합니다. 공개 설정 JSON이나 월드 백업에 키를 넣지 않습니다.

DB와 암호화 key 파일을 모두 읽는 같은 사용자 권한의 프로세스는 키를 복호화할 수 있습니다. 악성 프로그램, 계정 탈취, 메모리·swap 유출까지 막는 설계로 소개하지 않습니다. 파일을 자동 동기화하거나 공개 백업에 넣지 마세요. OS 계정과 디스크 보호도 별도로 관리하세요. 앱은 데이터 폴더와 vault 폴더가 링크가 아니고 사용자 소유이며 다른 사용자가 쓸 수 없는지 확인하지만, 같은 사용자 권한으로 실행되는 다른 프로세스는 이 확인의 보호 범위 밖입니다.

CLI·legacy UI는 기존 OS keyring/환경변수 호환을 사용하며 desktop vault와 자동 공유되지 않습니다. `.env.example`은 비밀 없는 형식 예시이고 실제 키를 평문 `.env`로 보관하는 사용법을 권장하지 않습니다.

키를 변경·삭제하려면 환경 설정을 사용합니다. Local → Session/Keychain 전환은 앱에 남은 Local ciphertext를 제거합니다. 기존 OS keychain 키 가져오기는 복사일 뿐 원본 항목을 남기지만, 앱이 그 항목이 있다고 기록하므로 키 삭제나 "키 삭제"를 선택한 앱 초기화 때 그 항목도 삭제합니다. Local과 Session 사이의 전환은 키체인에 손대지 않습니다. 키 파일 분실·암호문 손상 시 재입력이 필요할 수 있습니다. 앱의 OS keychain 항목은 서비스 이름 `PomiTranslate`에 계정 이름이 provider 이름(예: `openai`)인 것뿐이며, 이 이름 공간에는 PomiTranslate만 씁니다. 앱은 keychain을 나열하지 않고 다른 항목에는 손대지 않습니다. 이 항목은 사용자가 직접 요청할 때만 삭제합니다: 한 provider의 키 삭제, 그 provider를 Keychain에서 다른 저장 방식으로 전환, 또는 "키 삭제"를 선택한 앱 초기화(모든 provider)입니다. 이미 없는 항목은 삭제된 것으로 봅니다. 설정에 Keychain을 쓴 기록이 없으면(Keychain 방식을 고른 적이 없으면) 앱은 키체인에 접근하지 않습니다. 운영체제가 삭제를 거부하면 앱은 항목을 삭제하지 못했다고(`KEYCHAIN_UNCONFIRMED`) 알리며, 다시 시도하면 다시 삭제를 요청합니다.

**사용자 지정(Custom) 서버의 키**는 저장할 때의 서버 주소(스킴·호스트·포트, 경로는 제외)에 묶입니다. 주소를 다른 서버로 바꾸면 저장된 키를 새 서버로 보내지 않고 키를 다시 입력하라고 안내합니다(`CUSTOM_KEY_ORIGIN_MISMATCH`). 서버 주소가 기록되지 않은 이전 Custom 키도 다시 입력해야 할 수 있습니다. 공개 제공사의 키는 사용자 지정 서버로 보내지 않습니다. 일반 `http://`는 이 컴퓨터(localhost·127.0.0.1 등)에서만 허용하고 그 밖의 서버는 `https://`여야 합니다(`CUSTOM_ENDPOINT_INSECURE`).

데스크톱 앱의 Python 코어(JSONL)는 어떤 경우에도 OS keyring을 읽거나 쓰지 않습니다. 키체인은 Rust가 위 규칙으로만 다루고, 코어에는 요청에 필요한 키만 전달합니다. 선택한 제공사에 키가 없을 때 다른 제공사의 환경변수 키로 대신하지도 않습니다. CLI도 해당 제공사 자신의 환경변수·keyring 항목만 사용합니다.
