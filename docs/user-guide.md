# PomiTranslate 사용 안내

[English](user-guide.en.md) | 한국어 | [日本語](user-guide.ja.md) | [简体中文](user-guide.zh.md)

## 시작 전

![중요한 월드는 독립된 복사본으로 보관하세요](../assets/illustrations/docs/doc_backup_first_ko_v1.png)

현재는 개발 중인 앱입니다. macOS Apple Silicon의 개발 앱에서 주요 흐름을 확인했지만 정식 서명 배포·전체 OS 검증은 완료되지 않았습니다. [실행 준비](development.md)와 [지원 범위](support-matrix.md)를 먼저 확인하세요.

Minecraft나 서버를 종료하고 월드의 **독립된 복사본**을 만드세요. 자동 백업은 별도 백업을 대체하지 않습니다. 원본 맵·리소스팩의 권한은 그대로 원작자에게 있으며 MIT 소프트웨어 라이선스가 맵 재배포 권한을 부여하지 않습니다.

## 1. 환경 설정

### 처음 실행: 설정 도우미

![선택한 원문과 번역 지시는 제공사로 전송되며 요금이 발생할 수 있습니다](../assets/illustrations/docs/doc_api_notice_ko_v1.png)

처음 실행하면 안내 동의 다음에 **설정 도우미**가 열립니다. 도우미를 건너뛰어도(나중에) 스캔과 검토는 할 수 있고, 번역을 시작하기 전에만 설정하면 됩니다. 도움말의 **설정 도우미 열기**로 언제든 다시 열 수 있습니다.

1. **AI 제공사 선택:** OpenRouter, Gemini, OpenAI, Anthropic, Comet 중에서 고릅니다. 각 카드에서 **키 발급 페이지 열기**로 해당 제공사의 키 페이지를 기본 브라우저에서 엽니다. OpenAI·Anthropic 호환 서버를 직접 지정하려면 **고급: 직접 지정(Custom)** 을 고릅니다.
2. **API 키:** 키를 붙여 넣으면 바로 **연결을 확인**하고 사용할 수 있는 모델 수를 보여 줍니다. 이 확인은 입력한 키를 모델 목록 요청 한 번에만 쓰며, 마지막 단계에서 저장하기 전까지 저장하지 않습니다. 이미 저장된 키가 있으면 새 키를 입력하지 않아도 그 키를 사용합니다.
3. **모델 선택:** 추천 모델이 미리 골라져 있고(가장 저렴한 빠른 모델), 모델마다 100만 토큰당 입력·출력 가격을 보여 줍니다. 가격 정보가 없는 모델은 그렇게 표시합니다.
4. **번역 언어와 문체:** 도착 언어를 목록에서 고르거나 직접 입력하고, 문체를 정합니다.
5. **끝내기:** **설정 저장하고 끝내기**를 누를 때 제공사·모델·언어·문체와 입력한 키가 한꺼번에 저장됩니다. 중간에 창을 닫으면 아무것도 저장하지 않으며, 닫기 전에 계속 설정할지·버릴지 묻습니다.

### 환경 설정의 구성

환경 설정은 네 개의 탭으로 나뉩니다. 탭 이름 옆의 숫자는 그 탭에서 저장하지 않은 변경 수이고, 오류가 있는 탭은 따로 표시됩니다. 하단의 저장 영역은 **저장이 필요한 변경**이 있을 때만 나타나며 저장하거나 변경을 취소할 수 있습니다. 화면 표시 언어·화면 모드·알림 설정처럼 고르는 즉시 적용되는 항목은 저장 버튼이 필요 없습니다. 각 구역의 **이 구역을 기본값으로**는 그 구역만 초기값으로 되돌립니다.

### 번역 탭

- **제공사:** OpenAI, Gemini, Anthropic, OpenRouter, Comet, Custom endpoint 중에서 고릅니다. Custom의 endpoint URL과 wire format(OpenAI/Anthropic 호환)은 **고급** 탭에서 지정합니다.
- **API 키:** AI 번역에 쓸 본인의 키를 입력해 저장합니다. **연결 확인**은 입력한 키(또는 저장된 키)로 제공사에 모델 목록을 요청해 연결을 확인하며, 입력한 키를 저장하지 않습니다. 저장된 키는 값 대신 저장 여부와 방식만 보여 주며, 변경·삭제할 수 있습니다. 저장 방식은 **키 관리 및 보안**에서 고릅니다.
- **모델:** 목록에서 고르거나 모델 ID를 직접 입력합니다. 목록은 추천·전체로 나뉘며 검색할 수 있고, 번역에 맞지 않는 모델은 기본으로 숨깁니다. 단가 정보가 있으면 100만 토큰당 입력·출력 가격을 보여 줍니다.
- **모델 정보 조회:** OpenRouter는 공개 catalog를 자동으로 조회하고 수동 새로고침도 제공합니다. 이 조회는 설정을 저장하지 않으며 키와 월드 텍스트를 보내지 않습니다. 다른 제공사는 입력하거나 저장한 키가 필요합니다. 캐시·조회 실패·모델 미발견은 화면에 구분해 표시합니다.
- **단가 직접 입력:** 선택한 모델의 단가가 목록에 없을 때 나타납니다. 입력·출력 단가(USD/100만 토큰)를 직접 입력하면 그 모델의 비용 추정에 쓰며, 실행 화면에 "사용자 입력 단가 기준"이라고 표시합니다. 입력·출력 단가를 모두 입력해야 하고 0~1,000 USD 범위입니다.
- **추론(OpenRouter·Gemini):** 모델 기본값, 추론 끄기, 직접 설정 중에서 고릅니다. 모델 정보가 확인된 경우 지원 강도만 표시하고, 필수 추론 모델에서는 끄기를 선택할 수 없습니다. Gemini는 **모델 목록 불러오기**를 한 번 해야 모델의 thinking 지원 여부가 확인됩니다. Gemini 3 계열의 thinking은 기본으로 켜져 있어 짧은 번역에도 많은 사고 토큰(출력으로 과금)을 쓸 수 있으므로, 번역에는 **추론 끄기**를 권장합니다. 일부 최신 모델(3.7/3.8 flash, pro, `gemini-flash-latest`)은 완전히 끌 수 없어 앱이 그 모델이 허용하는 가장 낮은 단계로 자동 조정합니다. 사고 토큰은 결과 화면의 출력 토큰에 포함해 표시합니다.
- **사용량 확인(OpenRouter):** 저장된 키의 누적 사용 크레딧을 조회합니다. 번역 요청을 보내거나 설정을 저장하지 않으며, 같은 키의 다른 작업과 집계 지연 때문에 전후 차이가 이 작업의 비용과 정확히 같지는 않을 수 있습니다.
- **번역 언어·문체:** 도착 언어는 목록에서 고르거나 직접 입력합니다(UI 언어와는 별개). 문체는 표준/자연스러움(권장), 친근함/대화체, 격식체/명료함, 정중한 존댓말, 소설/이야기풍, 사용자 지정 시스템 프롬프트 중에서 고르고, "고유명사는 원문 유지"처럼 **추가 지시**를 덧붙일 수 있습니다. **AI로 지시문 다듬기**는 짧은 메모를 AI로 확장하는 기능이며 선택한 제공사에 별도 요청을 보내 비용이 발생할 수 있으므로 확인 후 실행하세요.
- **번역 검토와 비용 한도:** 두 설정은 [실행과 결과](#4-실행과-결과)에서 설명합니다. 기본값은 **월드에 쓰기 전에 번역 검토** 켜짐, 비용 한도 0(제한 없음)입니다.
- **용어집:** 모든 월드에 적용하는 용어집을 이 구역에서 편집합니다. 자세한 내용은 [용어집](#용어집)을 보세요.

### 스캔 범위 탭

- **월드 텍스트 종류:** 표지판, 책 페이지, 책 제목, 필터링된 책 제목, 엔티티·블록 이름, 아이템 이름, 아이템 설명, 텍스트 디스플레이, 명령 텍스트 컴포넌트 중에서 검사할 종류를 고릅니다. 추천 범위와 스토리 중심 preset, 모두 선택/해제를 제공하며, 명령어처럼 보이는 일반 문자열을 제외할 수도 있습니다.
- **이미 번역 언어로 작성된 텍스트 건너뛰기:** 재번역 비용과 시간을 줄입니다.
- **ZIP 리소스팩:** 월드 내부 `resources.zip`과 직접 선택한 외부 ZIP(최대 16개)을 함께 번역할지 정합니다. 범위가 바뀌면 다시 스캔해야 합니다.
- **저장형 수동 번역:** 모든 월드에 적용할 원문→번역문을 표에서 편집합니다. 검색, **행 추가**, 행별 오류 표시를 지원하고, **JSON 가져오기/내보내기**로 파일과 주고받을 수 있습니다. 원문이 정확히 같을 때만 쓰이며 API를 호출하지 않고, 후보 검토에서 입력한 번역이 우선합니다. 최대 5,000개, 각 32,000자, 전체 1 MB입니다.

### 고급 탭

- **속도·요청 한도:** 동시 요청 수, 요청당 묶음 문장 수, 분당 요청(RPM)·토큰(TPM) 한도, 요청 제한 시간, 최대 재시도 횟수, 생성 다양성(Temperature)을 조절합니다. 0으로 두면 별도 속도 제한을 두지 않습니다. 파일 쓰기 시도 횟수와 "파일 오류 시 다른 파일을 계속 처리" 여부도 정합니다. 계속 처리하면 결과가 부분 완료로 표시됩니다.
- **파일 및 번역 키 규칙:** 추가 리전 폴더, 제외할 파일 패턴, 번역 키 접두사를 입력 칩으로 추가·삭제합니다. 보통은 바꾸지 않아도 됩니다.
- **사용자 지정 엔드포인트:** Custom 제공사를 고른 경우에만 나타나며 주소와 통신 규격(OpenAI/Anthropic 호환)을 지정합니다.
- **설정 가져오기·내보내기:** PomiTranslate·기존 웹 UI의 JSON 또는 `translate.py`를 가져옵니다. Python 파일은 실행하지 않고 공개 문자열 상수만 읽습니다. API 키·월드 경로·UI 언어·외부 ZIP 경로는 가져오지 않으며 내보낸 파일에도 키가 없습니다. 가져온 값은 편집 화면에 불러올 뿐이며 저장해야 적용됩니다.

### 앱 탭

- **화면 표시 언어:** 한국어·영어·일본어·중국어 간체 중에서 고릅니다. 번역 도착 언어와는 별개이며 고르는 즉시 적용됩니다.
- **화면 모드:** 미리보기 타일(시스템·라이트·다크)이나 메뉴 막대의 보기 → 화면 모드에서 고릅니다. 고르는 즉시 화면·창 테두리·메뉴 체크 표시에 적용되며 저장 버튼 없이 설정 파일에 남습니다. **시스템**은 운영체제의 라이트/다크 설정을 따르고, 앱을 켜 둔 채 운영체제 설정을 바꿔도 바로 따라갑니다. 저장된 모드로 시작하도록 배경 처리를 구현했습니다. 최신 macOS/Windows 네이티브 창의 시작 깜빡임·색 검증은 아직 남아 있습니다.
- **작업이 끝나면 알림 받기:** 기본으로 켜져 있으며, 앱 창이 뒤에 있을 때 10초 넘게 걸린 스캔·번역·복원이 끝나면 운영체제 알림을 보냅니다. 알림 권한은 첫 알림을 보낼 때 한 번 요청하고 거부해도 작업에는 영향이 없습니다. 알림에는 월드 이름과 개수·상태만 담기며 원문·번역문·경로·키는 들어가지 않습니다.
- **업데이트:** 새 버전을 확인합니다. 하루 한 번 자동 확인(끌 수 있음)은 GitHub에서 최신 버전 정보만 받아 옵니다. 서명 검증 키가 들어간 배포본은 앱 안에서 설치 후 다시 시작하고, 그렇지 않은 빌드는 다운로드 페이지를 엽니다. 스캔·번역·복원 중에는 설치하지 않습니다. 업데이트 후 설정·저장된 키·백업을 유지하도록 설계했으며, 실제 서명 업데이트의 설치·데이터 보존 검증은 아직 남아 있습니다.
- **데이터 보관 위치:** 설정·작업·백업 폴더와 암호화된 키 폴더의 경로를 보고 열 수 있습니다. 앱 업데이트나 캐시 정리 도구는 이 폴더를 지우지 않습니다. 자세한 내용은 [업데이트·데이터 보존](updates-and-data.md).
- **초기화:** 두 번 확인한 뒤 모든 설정, 최근 월드, 이어서 할 작업, 모델 목록(선택하면 저장된 API 키까지)을 지우고 앱을 다시 시작합니다. **월드 백업과 원본 월드는 지우지 않습니다.**

### 확대·메뉴·창

- **확대:** 보기 메뉴에서 75–200%까지 확대할 수 있습니다. `Cmd/Ctrl+0`은 100%, `Cmd/Ctrl+2`는 200%입니다.
- **메뉴·단축키:** 파일 → 월드 열기(`Cmd/Ctrl+O`), 설정(`Cmd+,` macOS 앱 메뉴 / Windows·Linux는 파일 메뉴), 편집 → 찾기(`Cmd/Ctrl+F`, 후보 검토 화면의 검색창으로 이동), 도움말 → 도움말·시작 안내·단축키·오픈소스 라이선스·문제 신고(업데이트 확인은 macOS 앱 메뉴, 그 외 도움말 메뉴). 웹 링크는 앱 창이 아닌 기본 브라우저에서 열립니다.
- **창:** 창 크기와 위치를 기억해 다음 실행에 복원합니다(모니터가 바뀌어 화면 밖이면 다시 가운데로 옮깁니다). 긴 스캔·번역 중에는 Dock(macOS)·작업 표시줄(Windows)에 진행률이 표시되고, 창이 뒤에 있을 때 작업이 끝나면 아이콘으로 알립니다. 작업 중에는 창 닫기와 앱 종료(`Cmd+Q`)를 막고 이유를 알려 줍니다.
- **닫기 확인:** 저장하지 않은 환경 설정, 끝내지 않은 설정 도우미 입력, 저장하지 않은 용어집 변경, 아직 적용하지 않은 번역 검토 수정본이 있으면 창을 닫거나 앱을 종료하기 전에 저장·버리기·계속 편집 중에서 고르게 합니다. 다른 화면으로 이동할 때도 같은 확인이 나옵니다.
- **정보 화면:** 버전, 검증된 형식과 미지원 형식, 시스템 진단 정보, 저장소·라이선스·문의 링크, Minecraft 비공식 고지 원문을 확인할 수 있습니다. **오픈소스 라이선스**에서 앱에 포함된 구성 요소의 라이선스 전문을 볼 수 있습니다(도움말 메뉴에서도 열림).
- **도움말·시작 안내:** 사이드바의 도움말(또는 `F1`, macOS `Cmd+?`)에서 빠른 시작, 자주 묻는 질문, 단축키, API 키 발급 페이지, 문제 신고를 볼 수 있습니다. 처음 실행하면 안내 동의와 설정 도우미 뒤에 4단계 시작 안내가 한 번 나오며, 도움말 메뉴 → 시작 안내로 다시 볼 수 있습니다.

## 2. 월드 선택과 스캔

![스캔은 API 호출이나 월드 쓰기 없이 후보를 확인합니다](../assets/illustrations/docs/doc_scan_first_ko_v1.png)

복사본의 월드 폴더(level.dat 포함)나 서버 루트 폴더를 선택합니다. **월드 폴더 열기**, 창에 폴더(또는 `level.dat`)를 끌어다 놓기, 또는 **Minecraft 월드** 목록에서 고르는 세 가지 방법이 있습니다. 목록은 공식 런처와 Prism/MultiMC(macOS·Linux), CurseForge(Windows)의 saves 폴더를 읽기만 해서 월드 아이콘·이름·마지막 플레이 시각을 보여 줍니다. 앱은 월드를 안으로 복사하지 않고 직접 읽습니다. 원본 월드 대신 복사본을 고르세요. 화면에서 차원 구성, 데이터 형식(DataVersion), 월드 내장 리소스팩, 보존 중인 백업 수를 확인합니다.

Bedrock, 구형 `.mcr`, `.linear`, 게임·서버가 사용 중인 월드, 읽기·쓰기 권한이 없는 폴더, 월드 밖을 가리키는 경로는 시작 전에 차단됩니다.

월드 화면의 **스캔 시작**은 바로 스캔을 시작합니다. **월드 스캔**은 번역 API 호출·월드 파일 수정 없이 후보를 수집합니다. 결과에서 고유 문자열 수와 등장 위치 수를 구분해 읽고, 스캔 대상과 제외 목록도 확인하세요. 읽을 수 없는 청크는 원본 그대로 유지되며 경고로 표시됩니다. 모르는 포맷·압축·읽기 오류를 지원 완료로 간주하지 않습니다. 명령 블록의 `tellraw`/`title`은 기존 JSON 형식과 Java 1.21.5부터의 SNBT 형식(`{text:'Hello',color:gold}`)을 모두 읽으며, 바뀐 문자열만 원래 따옴표 형식대로 다시 씁니다. 형식을 해석할 수 없는 명령은 원본 그대로 두고 "형식을 해석할 수 없는 명령 N개" 경고로 알립니다. 스캔 화면의 **최신 스캔 보고서 내보내기**로 결과를 JSON 파일로 저장할 수 있습니다.

스캔 화면 위쪽의 **이 월드의 최근 작업** 요약에서 최근 스캔(후보 수)과 최근 번역(상태, 번역·실패 문장 수)을 볼 수 있습니다. 이어서 진행할 수 있는 작업이 있으면 **이어서 작업** 카드가 나타납니다.

## 3. 후보 검토

![한국어 후보 검토 화면 — 합성 데이터](images/locales/ko/review.png)

검색(문장 또는 위치), 정렬(월드 순서·원문순·빈도순·유형별), 텍스트 유형·상태 필터로 문장을 찾습니다. 항목을 선택하면 원문과 등장 위치를 확인하고 직접 번역문을 입력할 수 있습니다. 포함을 해제하면 해당 후보를 번역에서 제외합니다. 현재 필터에 해당하는 항목을 일괄 포함/제외할 수도 있으며, 일괄 변경 직후 나타나는 **되돌리기**로 취소할 수 있습니다.

- **등장 위치:** 차원 이름과 좌표(x·y·z)처럼 읽기 쉬운 형태로 표시합니다. 좌표가 있는 위치는 **텔레포트 명령 복사**로 게임 안에서 그 자리로 이동하는 명령을 복사할 수 있습니다(명령은 클립보드에만 복사하며 월드에는 아무것도 쓰지 않습니다).
- **후보 작업 메뉴:** 목록의 행에서 마우스 오른쪽 버튼(또는 키보드의 메뉴 키·`Shift+F10`)을 누르면 번역 대상 포함/제외, 직접 번역 입력, 원문 복사를 고를 수 있습니다.

`§` 서식 코드와 `%s`, `{0}` 같은 자리표시자는 게임 안에서 그대로 표시되도록 유지하세요. AI 번역문에서 필수 기호가 빠지거나 원문에 없던 기호가 추가되면(예: 색 코드를 하나 더 넣어 다른 단어의 색이 바뀜) 해당 문장은 원문을 유지하고 결과에 "서식 보호로 원문 유지"로 표시합니다. 코드가 같은 개수로 다른 단어 옆으로 옮겨진 번역은 허용합니다.

현재 후보는 같은 원문을 여러 등장 위치에 적용하는 단위입니다. 위치별 번역 분리와 translation memory는 후속 작업이며 아직 지원하지 않습니다. 모든 문장을 직접 번역하면 AI 번역 API 요청 없이 적용할 수 있습니다.

### 용어집

고유명사나 반복되는 용어를 일관되게 번역하도록 고정 규칙을 정합니다. 예를 들어 `Elder Mira`는 항상 `장로 미라`로 번역하고, `Nether`는 번역하지 않도록 정할 수 있습니다.

- **범위:** **모든 월드**용 용어집은 환경 설정 → 번역 탭에서, **이 월드만**의 용어집은 후보 검토 화면의 **이 월드 용어집**에서 편집합니다. 같은 원문이 둘 다 있으면 월드 용어가 우선합니다. 후보 상세에서 **용어집에 추가**를 누르면 선택한 문장을 바로 용어로 추가할 수 있습니다.
- **방식:** **번역하기**(고정 번역 지정) 또는 **번역하지 않기**(원문 유지). 메모와 대소문자 구분 여부를 정할 수 있습니다. 범위마다 최대 2,000개이며 원문 용어는 200자, 번역과 메모는 500자까지입니다. `§a` 같은 서식 코드는 넣을 수 없습니다.
- **가져오기·내보내기:** JSON 또는 CSV(열: `source`, `target`, `mode`, `note`, `caseSensitive`)로 주고받습니다.
- **동작:** 번역 요청에는 그 묶음의 원문에 들어 있는 용어만 포함합니다. AI가 규칙과 다르게 번역하면 앱이 같은 문장을 한 번 더 요청해 규칙을 상기시키고, 그래도 다르면 검토 화면에 **용어 확인 필요**로 표시합니다. 이 추가 요청의 비용은 예상 비용 범위에 반영됩니다.
- **번역 후 용어집을 바꾸면:** 적용 전에 영향받는 문장을 알려 주고 **영향받은 문장 다시 번역**을 요청합니다. 다른 번역과 스캔 결과는 유지됩니다.
- **저장 위치:** 용어집은 월드 폴더가 아니라 앱 데이터에 저장됩니다. [데이터 안내](privacy.md)를 보세요.

## 4. 실행과 결과

![한국어 실행 전 확인 화면 — 합성 데이터](images/locales/ko/run.png)

### 실행 전 확인

**번역 진행**에서 대상 월드, 언어, 제공사·모델, 전송할 문자열 수, 직접 번역 항목 수, 예상 요청 횟수, 예상 비용, 안전 백업 여부를 확인합니다. 예상 비용은 최소~최대 범위로 표시하며, 추론 토큰과 용어집 안내를 위한 추가 요청 여유분을 포함합니다. 그래도 추정은 청구 상한이 아닙니다. 재시도·계정/라우팅 차이와 제공사 집계 지연이 있으므로 실제 대시보드도 확인하세요. 직접 번역 항목만 적용하는 모드에서는 API 요청이 발생하지 않습니다.

**비용 한도(USD)** 는 이 화면이나 환경 설정 → 번역 탭에서 정합니다. 0이면 제한이 없습니다. 예상 최대 비용이 한도를 넘으면 시작하기 전에 경고가 나타나며, **설정 변경**이나 **그래도 시작**을 고를 수 있습니다. **그래도 시작**해도 실행 중에는 한도가 그대로 적용됩니다. 시작한 뒤 실제 비용이 한도에 닿으면 번역을 멈추고 월드에는 아무것도 쓰지 않습니다. 지금까지의 번역은 보관되므로 한도를 바꿔 이어서 번역하면 남은 문장만 요청합니다. 결과 화면의 **이번만 한도 없이 이어서 번역**은 한 번 더 확인을 받은 뒤 실행되며, 그 한 번의 실행에만 적용되며 저장된 한도는 바뀌지 않습니다.

### 진행

진행 화면에는 단계(텍스트 수집 → AI 번역 → 월드 파일 저장), 남은 시간 추정, 요청 수, 실패 건수와 **최근 번역** 문장이 표시됩니다. 실행 중 취소를 요청하면 협력적으로 중단하며 checkpoint를 사용해 남은 번역을 이어갈 수 있습니다. 취소·실패가 항상 파일 변경 0을 뜻하지 않으므로 완료 결과의 변경 수·오류·사용량을 확인합니다. 이미 기록한 파일이 있으면 백업 복원을 검토하세요. 재개 설정이나 파일 지문이 달라지면 재스캔이 필요할 수 있습니다. 처리 중에는 창 닫기와 앱 종료가 막힙니다.

### 번역 결과 검토 후 적용

환경 설정의 **월드에 쓰기 전에 번역 검토**(또는 실행 화면의 **적용 전에 번역 결과 검토**)가 켜져 있으면(기본값) 번역이 끝난 뒤 월드에 쓰기 전에 **번역 결과 검토** 화면이 열립니다. 이 시점에는 월드에 아무것도 쓰지 않았습니다.

- 표에서 원문·번역문을 검색하고 번역됨·실패·원문 유지·수정됨·용어 확인 필요로 거를 수 있습니다.
- 행을 선택해 번역문을 직접 고칠 수 있습니다. `§` 서식 코드와 `%s`, `{이름}` 같은 자리표시자가 원문과 다르면 오류로 표시하고 그 문장은 적용하지 않습니다. 비어 있거나 월드에 쓸 수 없는 문자가 있는 번역문도 마찬가지입니다. **AI 번역으로 되돌리기**로 고친 내용을 버릴 수 있습니다.
- 실패한 문장은 사유를 읽기 쉬운 문장으로 보여 줍니다(응답 지연, 키 거부, 요청 한도, 잔액 부족, 형식 불일치, 제공사 안전 필터, 네트워크 오류 등). **실패한 N개 다시 번역**은 그 문장만 다시 요청하며 예상 비용을 함께 보여 줍니다.
- **월드에 적용**을 누르면 확인 창이 나오고, 적용 전에 변경될 파일을 먼저 백업하고 검증합니다. 번역하지 못한 문장은 원문을 그대로 둡니다. 검토 중인 작업은 저장되어 있으므로 나갔다가 나중에 돌아와 이어서 적용할 수 있습니다.

검토를 끄면 번역이 끝나는 대로 바로 월드에 적용하며, 이때는 일부 문장이 실패했을 때의 동작(안전하게 정지 / 완료된 문장만 적용)을 실행 화면에서 고릅니다.

### 적용 뒤 번역문 수정

완료 결과 화면의 **번역문 수정**에서 이미 적용한 번역을 고칠 수 있습니다. 같은 검토 화면에서 문장을 고친 뒤 **수정한 N개 다시 적용**을 누르면, 앱이 ① 지금 월드 상태를 복구용 스냅샷으로 보관하고 ② 번역 전에 만든 백업으로 월드를 복원한 다음 ③ 저장된 번역과 수정한 내용을 새 백업과 함께 적용합니다. 이 과정에서 AI 요청을 보내지 않으므로 추가 비용이 없습니다. 복구용 스냅샷과 진행 기록을 남기므로 중간에 앱이 멈춰도 다시 열면 중단된 작업과 복구 지점이 남아 있습니다. Minecraft를 종료한 상태에서 진행하세요. 적용 뒤에 월드를 직접 바꿨다면 다시 적용할 수 없으며 월드를 다시 스캔해야 합니다.

### 결과

결과 화면은 다음 상태를 구분해 보여 줍니다.

| 상태 | 의미 |
| --- | --- |
| 완료 | 모든 번역을 적용했습니다. |
| 일부 완료 | 번역하지 못한 문장은 원문 그대로 유지했습니다. |
| 재시도 필요 | 월드 파일은 변경되지 않았고, 이미 번역된 문장은 저장되어 남은 문장만 이어서 번역할 수 있습니다. |
| 비용 한도로 중단 | 한도에 닿아 월드에 쓰기 전에 멈췄습니다. 번역된 문장은 보관되어 이어서 번역할 수 있습니다. |
| 실패 | 변경 파일 수와 오류를 확인하고 필요하면 백업을 복원합니다. |
| 취소됨 | 이미 번역된 문장은 저장되어 언제든 이어서 진행할 수 있습니다. |
| 월드 사용 중 | 게임·서버를 종료한 뒤 다시 시도합니다. |
| 월드가 바뀜 | 스캔 이후 파일이 변경되어 쓰기를 중단했습니다. 다시 스캔합니다. |
| 미지원 형식 | 월드 파일은 전혀 변경되지 않았습니다. |

결과에는 번역문 준비·번역 완료·원문 유지(고유명사 등)·번역 실패·서식 보호로 원문 유지 문장 수, 변경된 파일 수, API 요청 수, 사용 토큰과 실제 청구 비용이 표시됩니다. 번역 예시, 실패 문장 목록(사유 포함)과 서식 보호로 원문을 유지한 문장도 확인할 수 있고, **전체 번역문 보기**로 모든 번역을 열 수 있습니다.

게임에서 내용과 명령 동작을 직접 확인하세요. 번역문은 부정확할 수 있습니다. **최신 번역 보고서 내보내기**로 결과를 JSON 파일로 저장할 수 있으며, 보고서에는 월드 경로와 원문·번역문이 포함될 수 있으므로 공유 전에 확인하세요.

## 5. 복원

Minecraft와 서버를 종료한 상태에서 **백업 관리**를 엽니다. 월드와 복원 시점을 확인하고 복원 안내를 읽은 뒤 실행합니다. 복원 직전 현재 파일을 보관하는 recovery snapshot이 생성됩니다. 복원은 해당 파일의 백업 이후 편집·게임 진행을 되돌릴 수 있습니다.

백업은 번역 전 자동 백업과 복원 직전 안전 스냅샷으로 구분되며, 앱 데이터 보관소와 (구버전) 월드 폴더 내부에 있을 수 있습니다. 목록은 백업마다 간결한 카드로 보여 주며 백업 종류·만든 시각·파일 수·무결성 검증 여부를 확인하고 백업 ID를 복사할 수 있습니다. 외부 ZIP을 함께 번역했다면 복원 시 설정에서 같은 ZIP을 다시 선택해야 합니다.

Desktop은 자동 백업과 checkpoint 위치를 앱이 관리하며 백업 끄기·접미사·임의 경로 옵션은 제공하지 않습니다. 번역으로 새 대형 청크 파일이 생성된 경우에도 복원 전 현재 상태를 보관하고 번역 전 파일 구성으로 되돌립니다. 이 새 백업은 최신 앱으로 복원하세요. 기존 Legacy 백업은 계속 발견·복원할 수 있습니다.

검증되지 않은 백업·경로 오류·손상 경고를 무시하지 마세요. 백업은 모든 저장장치 고장이나 외부 수정에서 복구를 보장하지 않습니다.

## CLI

CLI는 같은 Python 코어를 사용하며 데스크톱 vault와 credential 경로가 다릅니다. 기존 CLI의 keyring/환경변수 호환을 유지합니다. 비밀을 명령 인자·평문 설정·Git에 기록하지 말고 기존 OS keyring을 사용하세요. 데스크톱에 키를 저장했다고 CLI에서 자동 공유되는 것은 아닙니다.

```bash
# --report-path는 월드 밖의 임시 경로로 지정합니다.
.venv/bin/python mc_world_translator.py \
  --world-dir "/path/to/World-copy" \
  --dry-run \
  --report-path "/tmp/pomi-scan-report.json"

.venv/bin/python mc_world_translator.py --help
```

주요 옵션:

| 옵션 | 설명 |
| --- | --- |
| `--dry-run` | 스캔만 수행하고 API 호출·파일 쓰기를 하지 않습니다. |
| `--expect-fingerprint` | 스캔 보고서의 지문과 월드가 다르면 쓰기를 거부합니다. |
| `--resume` | 저장된 checkpoint에서 남은 번역을 이어갑니다. |
| `--restore-backup` | 검증된 최신 백업으로 복원합니다. |
| `--no-backup` | 백업 없이 실행합니다. 권장하지 않습니다. |
| `--resource-pack-zip` | 번역할 ZIP 리소스팩 경로입니다. 여러 번 지정할 수 있습니다. |
| `--enable-resource-pack-translation` / `--disable-resource-pack-translation` | 설정과 무관하게 ZIP 번역을 켜거나 끕니다. |
| `--list-models` | 선택한 제공사의 모델 목록을 출력하고 종료합니다. |
| `--enhance-style-brief` | 짧은 문체 메모를 AI로 확장합니다. 별도 비용이 발생할 수 있습니다. |
| `--print-notices` | 첫 실행 안전 안내를 출력합니다. |
| `--provider`, `--model`, `--base-url`, `--wire-format`, `--api-key` | 제공사·모델·endpoint·키를 지정합니다. |
| `--target-language`, `--style-preset`, `--style-prompt`, `--custom-system-prompt` | 번역 언어와 문체를 지정합니다. |
| `--batch-size`, `--temperature` | 요청 묶음 크기와 생성 다양성을 지정합니다. |
| `--config`, `--data-dir`, `--report-path` | 설정 파일, 데이터 폴더, 보고서 경로를 지정합니다. |

macOS/Linux 예시이며 Windows에서는 `.venv\Scripts\python.exe`를 사용합니다. 실제 실행은 파일 수정과 API 청구를 발생시킬 수 있습니다.

## 문제 해결

![미지원 압축 리전에는 쓰지 않습니다](../assets/illustrations/docs/doc_unsupported_ko_v1.png)

| 증상 | 확인할 것 |
| --- | --- |
| 앱을 준비하지 못했습니다 | 코어 시작은30초, 최근 월드·백업 초기 정보는60초 안에 응답하지 않으면 중단됩니다. **다시 시도**를 누르고 반복되면 앱 재시작·최근 월드 저장 장치 연결을 확인하세요. 실행 중인 긴 번역·복원에 적용되는 제한은 아닙니다. |
| `AUTH_FAILED` | 환경 설정에서 API 키를 다시 확인합니다. |
| `NO_CREDIT` | 제공사 계정의 잔액·크레딧을 확인합니다. |
| `RATE_LIMITED` | 잠시 후 다시 시도하거나 동시 요청 수를 낮춥니다. |
| `MODEL_NOT_FOUND` | 모델 ID를 확인하거나 **모델 목록 불러오기**로 다시 조회합니다. Gemini의 예전 별칭 `flash`/`pro`는 이제 `gemini-flash-latest`/`gemini-pro-latest`로 바뀝니다. |
| Gemini 응답이 느리거나 "output token limit" 오류 | thinking이 켜진 모델입니다. 환경 설정에서 추론을 끄거나 `flash-lite` 계열을 고르세요. |
| `NETWORK_ERROR` | 인터넷 연결과 제공사 상태를 확인합니다. |
| 월드 사용 중 | Minecraft·서버를 완전히 종료한 뒤 다시 시도합니다. |
| 비용 한도로 번역이 멈춤 | 번역된 문장은 보관되어 있습니다. 한도를 바꾸거나 결과 화면의 **이번만 한도 없이 이어서 번역**으로 남은 문장만 이어서 번역합니다. |
| "고쳐야 할 번역문이 있습니다" | 표시된 문장의 `§`·`%s`·`{이름}` 같은 서식 코드를 원문과 똑같이 맞추거나 **AI 번역으로 되돌리기**를 누른 뒤 다시 적용합니다. |
| 용어 확인 필요 | 번역이 용어집 규칙과 다릅니다. 번역을 고치거나 용어집을 확인합니다. 그대로 적용할 수도 있습니다. |
| 적용 후 월드가 바뀌어 다시 적용할 수 없음 | 적용한 뒤 월드를 직접 바꾼 경우입니다. 월드를 다시 스캔합니다. |
| 스캔 결과가 오래됨 | 월드나 설정이 바뀌면 다시 스캔합니다. |
| 저장된 키 상태를 확인할 수 없음 | 키를 새로 입력하거나 삭제한 뒤 다시 저장합니다. |

문제가 있으면 [Issues](https://github.com/kim0040/PomiTranslate/issues)에 OS·버전·비밀을 제거한 재현 절차를 남겨 주세요. [면책 안내](disclaimer.md) · [데이터 안내](privacy.md)
